# Sokuo | Frontend Engineer CV

A personal CV website built with Next.js + TypeScript + SCSS.

## Requirements

| Tool | Version |
|------|---------|
| Node.js | v18+ |
| npm | v9+ |
| yarn | v1.22.22 |
| Next.js | v16.2.1 |

## Getting Started

Install dependencies:
```bash
yarn install
```

Run the development server:
```bash
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.
